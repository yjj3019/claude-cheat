## 부록 A — Claude Code(플러그인·에이전트) 실기동 검증 (신규 실측)

**설치 확인**: `C:\Users\user\.local\bin\claude.exe` **Claude Code 2.1.323 실존**.

| 실기동 | 실행 | 결과 |
|---|---|---|
| 실제 Claude Code 실제 세션 (실제 LLM 직접) | `claude -p "Reply with exactly OK" --model=deepseek-ai/DeepSeek-V4-Flash-0731_high` (실제 키) | **답변 `OK`, rc=0 — 실답변 도달** ✅ |
| 로컬 계정(비-loopback) | `ANTHROPIC_BASE_URL=172.21.135.113:4000` + 일반 키 | `Failed to authenticate … 401` → 계정/토큰 벽(실서버 자체가 토큰 거부) — 실질 벽일 뿐 통신은 도달 |
| 토큰 거부 직후 | 키 지정 시 | 실답변(위 줄) |
| 클라이언트 경고(비경고) | connectors disabled 경고 · unrecognized_model 경고 | 경고일 뿐 답변 도달 |

**진단 문구(실측)**: `claude Code`가 실제 서버와 실제 XH(401→200)까지 확인 — 플러그인/에이전트 요청은 클라이언트 즉시 — 프록시(loopback) 경유 시 동일(플러그인/에이전트=클라이언트 로컬) — 1회 부가 실측션 1회 — 계정 로그인(claude.ai)만 유일 잔여(미실시: 계정 소유자만).

**결론**: **proxy 모드에서 Claude Code의 플러그인/에이전트는 클라이언트 즉시 → 프록시는 재포장만 → 실기동 실무 크게 확인됨(`OK`)**. 단 명시: claude.ai 로그인(플러그인 포함 전체 통합)은 계정 정보 소유자만 재현 가능(실세션 실기동은 계정 실벽).
